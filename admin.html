How to publish an edit

  1. Select the page or file you want to edit.
  2. Sign in to GitHub as ArcticHolmes if prompted.
  3. Make the changes and choose Commit changes.
  4. Check Actions for the Pages deployment; reload the public site when it finishes.
Important limitations: This is a secure shortcut dashboard for GitHub editing—not the original drag-and-drop Owner Studio. GitHub Pages cannot securely save inline website edits, uploads or customer estimate submissions on its own. A database-backed editor can be added later.
