# Paradise Landscaping — GitHub Pages public website

This folder is the **public customer-facing static website**. It contains the welcome page, Florida page, Michigan page, styling, photos, and holiday calculator.

## Publish
1. Create a **public** GitHub repository named `paradise-landscaping`.
2. Upload **the contents of this folder to the repository root** (index.html must be at the top level).
3. Go to Settings → Pages → Build and deployment → Deploy from a branch.
4. Choose `main`, `/(root)`, and Save.
5. The expected address is `https://YOUR-USERNAME.github.io/paradise-landscaping/`. GitHub will display the actual URL in Settings → Pages once deployment succeeds.

## Before using as a live business website
- The estimate form opens an email program and does not submit to a server. Configure a secure online form destination.
- Official Florida and Michigan Google review links are not yet provided. Add them only after verification.
- The holiday calculator uses **illustrative sample rates**, not official prices. Update before advertising prices.
- Private Owner Studio was intentionally **not included**: password checks in JavaScript do not secure a public site. Use a real authenticated CMS/backend for editing.
- Local preview image uploads and reviews are **not published** in this package. Upload approved images into the repository or use hosted media storage.
- Confirm published contact information, claims, and service areas.
- The site currently uses inspiration imagery and illustration placeholders; replace with approved project images and label generated visuals accurately.

**Do not upload the older local preview ZIP to a public repository**, because it contains the browser-only admin prototype.
